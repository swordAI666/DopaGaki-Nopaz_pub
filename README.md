# TEN RUSH EXTREME

脳汁ドバドバの **10メイク数字パズル**。ブラウザだけで動きます（ビルド不要・外部ライブラリなし・画像/音声ファイルなし）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホなら任意のHTTPサーバー経由でアクセスしてください。

```sh
python3 -m http.server 8000   # → http://localhost:8000
```

### ルール

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 始点〜終点を対角とする**長方形**で囲む（1行・1列だけでもOK） |
| 合計が **10** | 消える（**TEN**）。空きマスを含めて囲んでもOK |
| **同じ数字だけ**（2個以上） | 消える（**TWIN**、得点は TEN の6割・時間回復は半分） |
| それ以外（2個以上を含む） | **MISS**：時間ペナルティ＋コンボ消滅 |
| 1個以下を囲む | 無視（ペナルティなし） |

```
2 □
□ □   ← 2 と 8 を対角に囲む。□（空きマス）は 0 扱いなので 合計 10 で消える
□ 8
```

### ドーパミン装置

- **COMBO** … 制限時間内に連続で消すと倍率が上がる（最大 ×12）。大きな範囲ほど得点は二乗で伸びる。
- **FEVER** … ゲージ満タンで約0.9秒の**溜め**（BGMが絞られ、ライザー音）→ **ドロップ**（ドンと全開）。8秒間、**得点×2・時間が減らない・ミスのペナルティ無し**。
- **JACKPOT 🎰** … 消すたびに抽選（外れが続くほど当たりやすい）。リールが回り、次のどれかが当たる。
  - `DIGIT PURGE` 盤面でいちばん多い数字を全消し＋得点
  - `SCORE BURST` 大量ボーナス点
  - `TIME BANK` +8秒
  - `GOLD SHOWER` ランダム14マスを★金マスに
  - `FEVER` 即フィーバー
- **LAST SPURT** … 時間が0になっても即終了せず、**最後の6秒だけ得点×3・ペナルティ無し**。消すほど少し延びる（最大9秒）。1ゲームに1回で、ここでゲームが終わる＝最高潮で終わる。
- **★金マス** … 含めて消すと +2秒 & スコア2倍。
- **WAVE** … 盤面が約12%まで減ると新しい数字が降ってくる（+5秒・ボーナス）。ただし WAVE が進むほど時間の減りが加速する。
- **ヒットストップ／ズーム／RGBずれ** … 大きく消した瞬間・フィーバー・ジャックポットで一瞬フレームが止まり、盤面がドンと膨らむ（ズーム中もドラッグ判定はずれない）。
- 残り10秒は画面が赤く脈動。放置すると光るヒントが出る。
- BGM はコンボが続くほどフィルターが開き、テンポも上がる（WebAudio で生成）。

### 難易度

| | 開始時間 | コンボ猶予 | 減りの加速/WAVE | ミス | スコア倍率 |
| --- | --- | --- | --- | --- | --- |
| RUSH | 60s | 3.2s | +0.10 | -1s | ×1 |
| **EXTREME** | 45s | 2.6s | +0.16 | -2s | ×1.5 |
| INFERNO | 30s | 1.9s | +0.25 | -3s | ×2.5 |

### 設定（タイトル画面）

- **COLOR ASSIST** … 足して10になるペア（1-9 / 2-8 / 3-7 / 4-6 / 5-5）が同じ色になる。OFFで玄人向け。
- **EFFECTS: LITE** … 画面の揺れ・フラッシュ・点滅を抑える（`prefers-reduced-motion` なら初期値がLITE）。
- **SOUND** … ON/OFF。

## 構成

```
index.html   画面の骨組み（HUD・盤面・タイトル/結果オーバーレイ）
style.css    ネオン調スタイルとアニメーション
game.js      ルール判定・スコア・コンボ/フィーバー・演出・入力
audio.js     WebAudio による効果音とBGM
```

チューニング値は `game.js` 冒頭の `DIFFS` / `FEVER_DUR` / `GOLD_P` / `TIERS` などにまとまっています。
`index.html?debug` で開くと `window.__tr`（盤面の全解探索、ジャックポット/フィーバーの強制発動など）が使えます。
